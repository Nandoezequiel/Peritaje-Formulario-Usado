# Peritaje — Formulario de Usado

Formulario de revisión de un vehículo usado (peritaje o permuta). Permite registrar el estado del vehículo y generar un documento imprimible en una sola hoja A4.

## Cómo usar

1. Abrir `index.html` en el navegador (no necesita servidor ni instalación).
2. Completar los datos del vehículo.
3. Seleccionar las piezas con daño en el diagrama interactivo de carrocería.
4. Registrar el estado de cada neumático.
5. Completar el estado técnico (prueba de manejo, prueba estática, interior, capot).
6. **Imprimir / Guardar PDF** para obtener el documento en una hoja A4, o exportar a Word.

## Archivos

| Archivo | Descripción |
|---|---|
| `index.html` | Aplicación completa |
| `1.jpg` … `5.jpg` | Vistas del vehículo para el diagrama (lateral izquierda, superior, lateral derecha, frontal, trasera) |

## Funcionalidades

- Diagrama interactivo de carrocería con 5 vistas y 17 piezas seleccionables.
- Neumáticos con 3 estados visuales: sano, medio uso, cambiar.
- Impresión compacta: solo muestra los ítems marcados, todo en una hoja A4.
- Exportación a Word (.docx) sin dependencias externas.
- Campos de valor de permuta y gasto previsto de preparación.
